# 一点光：产品定义与体验

## 核心价值

“今天被一个陌生人理解；多年后，被当年的自己鼓舞。”

面向需要片刻陪伴的听众，以及愿意分享真实经历的普通人。声音短、表达轻、入口安静。允许难过，不强迫乐观，不把鼓励变成成功学。

## 两条主要旅程

**听众：**进入首页 → 选择此刻的心情 → 点开一段精选声音 → 看署名与日期、阅读文字稿 → 收藏或送出力量 → 分享给需要它的人。

**录制者：**抽一张灵感卡 → 录制或上传 → 试听 → 写标题、署名、日期 → 选择公开/私密和未来年份 → 登录保存 → 在声音年鉴中重听、回应、导出。

## 有辨识度的创意

1. **心情收音机**：不按流量制造焦虑，按“有点累、需要勇气、重新开始、给未来的我”找到一段声音。
2. **未来回声**：多年后回应当年的声音，形成独立录音的关联。原音频与原署名不被覆盖。详情中可在原声和后来回应之间切换。
3. **声音年鉴**：录制日期与入库时间分开，按年份寻找自己的变化；十年和二十年目标只做标记，今天仍可收听。
4. **灵感信箱**：提供具体的句子起点与表达结构，引导用户讲自己的经历，减少空泛口号。
5. **善意回应**：只保留“给了我力量”与收藏；无粉丝榜、频道支持公开交流、无私信，减少争论和表演压力。
6. **可带走的记忆**：分卷 ZIP 含原音频和完整时间/署名信息，用户掌握自己的记忆副本。

## 首页内容策略

首页只展示通过审核且被精选的真实投稿。没有精选内容时，使用明确标注的产品示例帮助理解交互；示例不积累虚假点赞。

精选维度：真实具体、尊重情绪、可理解的陪伴、声音清晰、内容有边界。录音设备不决定精选资格；表达真实比播音技巧重要。

首次冷启动建议邀请 15–30 位愿意真诚表达的人，每个心情先收集 5 段。不要购买或假造用户。审核员完整收听，避免只看文字稿。

## 内容管理

公开投稿状态：pending → approved / rejected。approved 可选择 featured；公开作者可撤回为 private。首页精选与普通公开独立。退回说明写入个人档案，审核动作保留日志。

禁止攻击、歧视、营销、暴露隐私、侵权、诈骗，以及不切实际的医疗/成功保证。声音可以承认困难；“正能量”指给人理解与力量，不等于不允许悲伤。

## 衡量价值

优先观察：听完率、听后“给了我力量”的比例、真实投稿通过率、录音完成率、用户主动回来重听自己声音的次数。当前版本没有部署这些统计采集，不展示编造的数据。

## 后续版本

- 真实社区验证后：账户恢复渠道、到期提醒的明确订阅与取消、本人授权的语音转写。
- 长期运营：有恢复演练的备份、音频完整性校验、退出运营的导出计划。
- 有稳定贡献者后：主题征集、年度回顾、给未来的自己发送一封带声音链接的信。
- 不宜早期加入：排行榜、无限滚动、语音私信、付费提高首页曝光。

## 商业化方向（未实现）

优先保留基础收听和个人导出免费。后续可尝试付费声音纪念册、家庭私密档案、活动声音墙；收费应围绕整理和服务，不能让付费决定谁的鼓励更值得被听见。

## 本轮主题与频道更新

首页主题采用直接邀请参与的原创提问。INFP 主题沿用用户给出的句式；人格标签仅作为轻松话题，不宣称声音能推断人格。其他主题参考短视频中常见的碎碎念与晚安互动方式，而非声称获得热度排行验证。参考：[INFP 日常分享](https://www.douyin.com/video/7675323910079030939)、[晚安互动](https://www.douyin.com/video/7682081183904566898)。

吹水频道不要求励志：可以聊今天吃什么、生活小事、脑洞和普通心情。允许疲惫与求助；屏蔽目标是辱骂、攻击、消极诱导与营销。文字规则初筛后，三类媒体统一等待人工审核；每 15 秒更新公开消息，不是即时 WebSocket 聊天。
