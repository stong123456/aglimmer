## 收录方式

- LibriVox 录音通过 Internet Archive 原文件地址直连播放（浏览器连接原站，不经本站转存），录音文件名和时长与来源元数据逐条匹配，保留志愿者来源页署名。未能逐一确证朗读者全名时不把诗人姓名当作朗读者。
- LibriVox 的公有领域声明依据美国法律，不能等同全球通用的授权。本站保留这一地区限制，使用来源原文件流，不托管、不剪辑、不重新分发音轨；若来源权利状态有疑问，先暂停展示再核对。
- 现代演讲取自 Stanford、TED、Harvard Magazine、Maharishi International University 官方发布频道。卓别林《大独裁者》结尾片段取自 Charlie Chaplin 官方频道，版权归原权利人，**不标作公版电影**。以官方 YouTube 播放器展示，保留画面、控制、署名及原站链接，不抽取 MP3。
- 来源页可以取消嵌入或限制地区访问。即使元数据可获取，也不代表各地区都能播放。始终显示原站入口；不通过代理转存来绕过限制。
- 未点击收听前不加载外部音视频或 YouTube SDK。用户主动打开后连接 Archive.org 原文件或 YouTube 官方播放器。YouTube 使用隐私增强域名；这不表示零数据传输。统一队列支持来源音频与 YouTube 官方 IFrame API 的播放完成事件、暂停和手动下一段；YouTube 保留可见画面与控制，不能作为隐藏音轨播放。浏览器限制自动播放时停住并提示用户点击继续。

## 反馈与暂停

无需登录即可反馈来源、版权或播放问题，10–300 字、每小时 10 次、重复未处理反馈合并。原始 IP 不写入反馈表。反馈进入管理员举报队列。管理员可暂停/恢复素材展示，所有操作记录至审核日志。公开素材状态接口不可用时，内容库暂缓显示并提供重试。暂停展示不会声称能删除第三方平台原作。

投稿引导仅预填作品来源与听后感标题，不预填现代台词或演讲全文，不鼓励用户将原音轨冒充自制作品。复制功能只复制署名与来源链接。
