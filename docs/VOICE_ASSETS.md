# 首页示例声音制作记录

使用 HeyGen Speech 工具生成，输出 MPEG Layer 3 音频，保存为本地 MP3。所有文案为产品原创示例，人物与日期用于演示，不能当作真实用户投稿。

| 文件 | 音色方向 | 工具音色 | 时长 |
|---|---|---|---|
| warm-female.mp3 | 温柔女声 | Gail in car | 16.27 秒 |
| grounded-male.mp3 | 沉稳男声 | Martin Li | 16.61 秒 |
| bright-young.mp3 | 清亮少年声 | Karo Yang（Young） | 15.28 秒 |
| future-female.mp3 | 温柔女声，时光信 | Gail in car | 20.11 秒 |

声音制作保留已有原文，使用 0.8–0.94 速度系数与 SSML 秒级停顿。情绪方向是平静陪伴、理解与轻柔鼓励，不使用背景音乐覆盖人声。实际脚本见 `lib/shared.ts` 的文字稿。

目前连接中未找到可确认的适用中文童声音色，采用较年轻的中文音色并明确标为“少年声”。没有模仿特定真人或儿童。

生成音频作为网站资产保存到 `public/audio/`，运行时不需要 HeyGen API 密钥，不依赖临时外链。音质与主观情绪仍建议由运营者试听后挑选最终版本。
