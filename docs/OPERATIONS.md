# 运营、部署与长期保存

## 上线前必做

- 网站已发布至 https://aglimmer.xyz ，域名、HTTPS、D1/R2 健康检查已通过；GitHub 已同步。下列运营配置仍需逐项验收。
- 已核对所有者的真实登录身份并配置生产 ADMIN_USER_IDS，重新部署后管理员权限已生效。后续新增管理员仍须逐一核对产品账户编号；任何访客不得自动成为管理员。
- 发布时允许匿名访问首页，业务账户由 Supabase 验证。生产代码忽略自填身份头，仅接受经身份供应商验证的会话。
- 匿名用户可听公开声音；只有作者可以读取自己私密的音频、文本、导出记录。审核员仅能读取公开投稿，包括待审核。
- 使用两个真实账户验证账户隔离；本地固定测试账户不能替代这个生产验证。
- 调整实际服务条款、隐私与联系渠道，明确公司/运营者主体与停止服务安排。
- 检查 iPhone Safari 和 Android Chrome 的真实麦克风权限、音频格式、锁屏/后台中断行为。

## 备份方案

站内维护接口已实现每日加密恢复副本、原始媒体分块 SHA-256 校验、删除清单以及样本还原验证。云端任务每天 04:20（Asia/Shanghai）执行；首次真实运行与任务状态见原生 Sites 任务和管理员维护面板。完整无人值守说明在 `docs/MAINTENANCE.md`。

- 数据库快照使用 D1 batch 读取固定业务表，保留录音的原日期与署名。临时验证码限流记录不备份。
- 媒体按最多 4 MB 分块，AES-256-GCM 加密，写后读回校验；同一内容分块复用，不覆盖原文件。恢复副本放在私有 R2 `__backups__/`，没有公共下载端点。
- 目标保留 7 天，由日常维护清理；任务异常可能延迟。默认总媒体副本上限 256 MB、对象目录上限 1000 项、每表最多 10000 行，达到任一上限失败并提示，不能把部分副本标成完成。
- 这些是同站点恢复副本，**不是跨账号或异地备份**。另一账户、离线介质和独立密钥保管仍需运营者建立，不能据此承诺十年或永久保存。
- 每次任务检查最近完成快照，合并最新删除清单，把一个不超过 8 MB 的原文件样本还原到私有临时对象并读回校验，然后删除临时对象。没有合适真实样本时只验证 canary 流程，明确不记作完整原文件恢复。不会覆盖线上数据库。
- 自动化测试另行把真实生成格式的快照恢复到独立 Miniflare D1，验证署名、原日期、私密权限与原字节。整库生产灾难恢复和跨账号还原不等于该样本校验，须运营演练后另行确认。
- 用户删声音、删消息、替换/删头像或完成注销时记录删除清单；恢复投影会去除已删除内容，将旧公开声音变为私密、消息转为待审核，避免旧权限复活。
- 备份密钥仅在生产运行环境中以 secret 保存。不得随意替换 `BACKUP_ENCRYPTION_KEY`；替换会导致旧副本无法解密。站点整体丢失时，同站点副本及运行环境中的密钥都可能不可用，用户仍应定期完整导出并独立保存。

## 停止服务计划

提前公告并提供至少 90 天导出窗口。停止接受新投稿后仍允许登录、下载原音频和元数据。联系不到的用户不应以邮件已发出作为履行完毕的证明；站内公告持续可见。

## 运行限制与监控

- 监控数据库/R2 错误、失败上传、不可播放音频、审核等待时间和存储增长。
- 现有每小时投稿上限是数据库读取后检查，适用于小规模 MVP；生产高并发需要原子限流与全站滥用防护。
- 上传先存 R2，再写 D1；数据库失败时清理对象。删除先停止数据库提供，再删除 R2。若删除对象失败，应在运营清理任务中清除孤立对象。
- 每段最长 90 秒、10 MB，账户 200 段/500 MB。上传时按实际格式分析时长，不依赖用户提交的 duration 字段。
- ZIP 每卷约 40 MB，完整元数据在每卷内；大量下载可能需要浏览器允许多个文件下载。
- 旧 AI 示例音轨已退役；网络经典在独立素材库以来源播放器展示，权利记录见 VOICE_ASSETS.md。
- 公共频道每分钟最多 5 条文字/图片消息，账户最多 1000 条消息与 100 MB 图片；语音使用原有声音配额。规则仅作窄范围初筛，音频、图片与复杂语境需人工审核。声音、频道投稿与举报审核台已独立分页（每页 20 项）并提供完整待办计数；公共频道每页 60 条，可继续读取更早的文字、图片和语音；查看历史时暂停自动更新，返回最新后恢复。历史页与最新页沿用相同的审核及作者权限。

## 邮件与真实登录验收

独立 Supabase 项目、mail.aglimmer.xyz 发信域、仅限该域名的 Resend SMTP 密钥和品牌验证码模板已配置；验证码有效期 10 分钟，服务端生成 8 位码，前端完整接收。所有者已确认真实收码和首次登录；退出并重新登录、第二个真实账户的隔离检查仍待验收，不能用合成测试替代。

## 外部依赖

生产业务身份依赖 Supabase Auth，邮件经 Resend 发送；托管依赖 Cloudflare Workers/D1/R2。界面字体优先 Noto Serif SC（当前 Google Fonts）并提供系统中文宋体回退。正式运营如需避免外部字体请求，可改为自托管有许可的字体文件。

## 运行检查与审核管理员

登录后在“我的声音 → 账户设置”复制账户编号，由所有者确认归属后填入生产环境 ADMIN_USER_IDS 并重新部署。不能按邮箱自动提权，也不能把第一个注册者自动设为管理员。管理员可在审核台查看运行检查：数据库/存储、身份配置、审核名单、人机验证、真实邮件送达和备份恢复验收。

EMAIL_DELIVERY_VERIFIED=true 仅在所有者真实收码、登录、退出并重新登录成功后填写。BACKUP_RESTORE_VERIFIED_AT 仅在完成实际恢复演练后填写 ISO 时间；这两个配置是运营验收记录，不会自行测试邮件或备份。人机验证仍需在 Supabase 配置 secret、本站配置 public site key。

可运行 `npm run check:live` 只读检查正式首页与 D1/R2 健康接口，失败返回非零退出码。定期维护会运行音源检查与备份；`check:live` 仍是独立的只读工具，本机网络阻断需结合托管日志判断。

## 注销申请处理

1. 用户先导出档案，确认理解后输入 CLOSE 提交申请。开始处理前可以撤回；申请本身不会立即删除内容。
2. 管理员在审核台“账户注销申请”核对申请及 Supabase 用户编号。先在 Supabase Authentication 删除对应身份，再确认并输入 DELETE 处理本站数据。不得处理没有申请的账户；管理员本人需由另一位管理员处理。
3. 服务器持久保存清理状态和对象清单，再事务性清除该用户的档案、声音、图片、收藏和相关记录。其他作者的独立回复保留，原关联解除。对象删除中断后，后台可重试；处理中用户不可撤回。
4. 关闭身份仅保留 subject 的 SHA-256 标记以防旧会话重新生成档案，不保存邮箱。处理完成后对象清单清空。
5. 离线/历史备份按实际公布的保留与删除周期处理；恢复旧数据库前必须合并最新注销清单，避免旧公开内容重新出现。站内加密副本按上述周期清理；独立异地副本仍需运营者管理。

## 离线备份文件的加密、校验和恢复

该工具处理个人导出的 ZIP 或运营者已取得的快照文件。它不获取托管平台凭据，也不执行全站远程备份或线上数据库恢复。

```sh
node scripts/archive-vault.mjs seal /私有目录/档案.zip /私有目录/档案.agvault
node scripts/archive-vault.mjs verify /私有目录/档案.agvault
node scripts/archive-vault.mjs open /私有目录/档案.agvault /私有目录/恢复档案.zip
```

口令在终端隐藏输入（至少 12 字符），可由密码管理器生成并独立保存；不要放在命令参数或仓库。AES-256-GCM 认证整个文件与头部，scrypt 派生密钥；校验失败不会发布恢复文件，目标已存在时拒绝覆盖。verify 只读验证并返回原文件 SHA-256，不生成明文文件。测试覆盖原字节恢复、错误口令、文件篡改、空文件与防覆盖。

## 个人档案完整性与回忆提醒

个人导出的 ZIP 每卷包含 `checksums.json`（SHA-256、大小、路径、导出时间）及 `VERIFY.txt`。用 Python 3 运行 `python3 scripts/verify-export.py /路径/档案.zip`，只读比对、不解压、不覆盖。每卷都带完整档案元数据；校验值验证传输完整性，不证明录音者身份或签名真实性。独立异地全站备份仍未启用。

声音周年提醒生成用户自行导入的 `.ics` 文件；默认仅包含一般提醒，不包含声音标题、署名、私密媒体地址。用户主动勾选后才加入标题/署名，并提示日历可能同步第三方服务。年度回顾按本人填写的录制日期归类，与服务器保存时间分开。

素材投诉可在审核台“收到的举报”看到，点击暂停展示立即移出当前选集；核对后可恢复。处理按钮与标记已处理分开，不应仅关单而不检查来源。原站播放器在其他地区的可用性应由运营者定期抽查，检查失败先暂停并保留审计记录。

## 来源队列与睡眠模式

`/api/classics?catalog=1` 提供公开来源目录（排除暂停项），首次加载一次；后续每分钟或回到窗口时只请求轻量素材状态。来源被暂停时，正在收听的对应素材停止，待播时再检查暂停清单。暂停展示不会删除第三方原作。

播放队列保存在当前页面内存，关闭页面不会自动恢复或开始播放。收听位置保存在当前浏览器 `glimmer-progress:<id>`；私密账户切换/退出会关闭正在使用的来源队列，音频访问权限仍由原业务端点校验。

睡眠倒计时使用绝对截止时间，并在每秒、页面恢复及播放事件核对；播放完成先检查计时/指定终点，再决定自动下一段。清单结束不循环。来源故障或自动播放被阻止时保留错误提示和原站入口，需用户继续操作。不能承诺被系统冻结或关闭网页后执行任务。
